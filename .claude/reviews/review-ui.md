## Nice to Have (style, consistency)

- **`SidebarLayout` uses hardcoded inline colors instead of tokens** — `packages/ui/src/layout/sidebar-layout.tsx:94-98` and `132-136` — `background: "rgba(13,18,23,0.95)"` and `borderRight: "1px solid rgba(255,255,255,0.05)"` bypass the `--ui-sidebar-bg` / `--ui-border` tokens that already exist in the `app` mode. Fix: switch to `hsl(var(--ui-sidebar-bg))` / `hsl(var(--ui-border))` with sensible fallbacks for modes that don't define them.
- **No tests in `packages/ui`** — zero `__tests__` or `*.test.*` files. `SidebarLayout` has non-trivial drag/keyboard logic (min/max clamp, Home/End, mouseup cleanup, cursor restore). Fix: add a Vitest + Testing Library test for keyboard resize clamping and `mouseup` listener teardown.
- **`Textarea` lives in `apps/web/components/ui/textarea.tsx`** — belongs alongside the other primitives. Fix: move to `packages/ui/src/components/textarea.tsx`, export from the barrel, then delete `apps/web/components/ui/` and `apps/web/lib/utils.ts`.
- **`base.css` `--space-*` scale is declared but unused** — `packages/ui/src/tokens/base.css:3-11` — grep for `var(--space-` across the repo returns no hits. Fix: either start using these to replace ad-hoc spacing in map-modules, or delete. Needs verification if they're intended as a public API.
- **Two parallel theming systems (`data-theme` vs `data-mode`) with different variable namespaces** — `packages/ui/src/tokens/themes.css` — unfamiliar readers will find the shadcn-style `--primary`/`--background` next to `--ui-bg`/`--ui-surface` confusing. Fix: add a one-line note at the top of the file explaining that `data-theme` drives map chrome (shadcn vars, set by `manifest.theme` in `map-shell.tsx`) and `data-mode` drives page chrome (`--ui-*` vars, set by the FOUC script).
